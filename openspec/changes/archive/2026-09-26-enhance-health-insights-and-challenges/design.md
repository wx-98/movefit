## Context

MoveFit 已在 iOS 15 的 SwiftUI、Core Data 和 HealthKit 边界上实现基础动作库、挑战、首页指标和历史趋势。现有动作 DTO 已接收 `images`，但详情页仅消费首张图；挑战为少量静态内容；长周期趋势图的分桶和坐标刻度没有统一模型。AI 服务尚未部署，HealthKit ECG 数据属于高敏感健康信息。

## Goals / Non-Goals

**Goals:**

- 展示动作开始与结束两张远程图片，并在缺图或加载失败时保持说明可用。
- 用本地可验证规则提供至少 60 个挑战、层级筛选和准确进度。
- 用统一时间分桶模型重建历史趋势的坐标、选中状态、平均线和今日对比。
- 为首页四项指标提供数据来源明确的详情页；在可用时读取 ECG 元数据和分类。
- 定义不泄露原始健康数据、可按权益控制、可替换后端的 AI 洞察接口，并先以本地低风险洞察降级。

**Non-Goals:**

- 本变更不诊断心律疾病、不提供治疗建议、不将 ECG 波形或 HealthKit 原始样本上传。
- 本变更不接入未部署的 AI 端点、不实现支付、订阅购买或服务端挑战同步。
- 不新增第三方图表、AI 或网络依赖。

## Decisions

### 1. 动作媒体使用有语义的双帧分页

`Exercise.imageURLs` 保持为 URL 数组；动作详情根据索引显示“起始动作”“结束动作”，使用可访问的 SwiftUI 分页视图并在单张或失败时显示明确状态。相比只展示缩略图，这能保留接口顺序语义；相比下载并持久化图片，不扩大本地健康或网络缓存范围。

### 2. 挑战由可组合模板生成稳定目录

在 Domain 中定义挑战类别、目标单位、适用运动和难度。使用固定 ID 的模板生成至少 60 条稳定挑战，并按“跑步 / 骑行 / 力量 / HIIT / 步数 / 恢复”与“入门 / 进阶 / 目标”层级浏览。相比临时随机生成，可持久化加入状态并可写单元测试；服务端挑战接口将来替换 Repository 而不改变 UI。

### 3. 趋势先生成领域分桶，再绘制 iOS 15 兼容图形

新增带 `startDate`、`endDate`、`value` 的日/周/月分桶模型：周按日、月按周、半年与年按月聚合。图形从同一分桶集合计算非零安全上限、柱高、平均线与命中测试；点击柱体保留选中分桶并显示日期和值。相比 View 中直接按数组索引绘制，避免月/年切换后的刻度错位。

### 4. 健康指标详情与 ECG 通过 HealthKit Adapter 隔离

首页只发出指标点击事件；ViewModel 请求 `HealthMetricDetailProviding`，由 HealthKit Adapter 查询步数、距离、当前/静息心率及 ECG 分类。ECG 仅返回记录时间、分类、症状标记和可选平均心率等最小领域摘要，不复制波形；未授权、无设备、无记录均与“拒绝”区分。

### 5. AI 洞察使用权益感知的摘要契约和本地降级

定义 `AIHealthInsightRepository` 协议、`InsightEntitlementProvider`、只包含聚合数值与用户主动选择范围的请求/结果领域模型。远程实现仅预留 DTO、路径和错误类型，不在未配置时发请求；本地规则引擎返回带来源与生成时间的非诊断洞察。UI 依据权益状态展示可用、升级说明或本地洞察，付费策略由未来后端客户端配置映射，而非硬编码会员判断。

## Risks / Trade-offs

- [`.local` 或 HealthKit 权限不可用] → 页面保留空状态、来源和重新授权入口，不能以演示数据替代。
- [ECG 记录可能没有波形或分类] → 仅展示可读取字段，使用中性“请留意/咨询专业人员”措辞。
- [60 条本地挑战造成页面拥挤] → 分类、难度和搜索分层，默认只突出精选集合。
- [未来 AI API 变化] → 领域请求与 DTO 分开，版本化 capability key，远程错误不可覆盖本地洞察。
- [长周期图表的数据密度] → 固定分桶数与最小柱宽，使用选择详情而非全部标签。

## Migration Plan

1. 保留现有本地挑战加入 ID；新增挑战使用稳定 ID，不改变历史记录。
2. 更新动作详情以消费已存在的图片数组，不迁移网络数据。
3. 先发布本地趋势、指标详情和 AI 降级；后端可在客户端配置发布 capability/权益后逐步启用远程实现。
4. 若新图表或洞察异常，回退到现有摘要卡片与本地养护建议，不影响运动和 HealthKit 原始读取。

## Open Questions

- 未来 AI 服务的认证、配额、模型版本和付费商品 ID 由后端契约确定；本次仅固定客户端扩展点。
- ECG 原始波形是否需要在未来单独、明确同意后处理，需先完成隐私评估与医学合规设计。
