## MODIFIED Requirements

### Requirement: 徽章与排行榜
系统 MUST 展示由本地真实健康与运动数据计算的已解锁和未解锁徽章；排行榜仅在后端提供正式接口时展示，当前无接口时 MUST 显示明确不可用状态且不得使用演示排名。

#### Scenario: 达成徽章条件
- **WHEN** 用户的真实运动数据首次满足徽章规则
- **THEN** 系统只解锁一次并记录解锁时间

#### Scenario: 排行榜接口缺失
- **WHEN** 用户打开排行榜且主后端未定义排行榜 API
- **THEN** 系统说明“当前后端未提供排行榜接口”，不显示模拟用户、排名或分数
