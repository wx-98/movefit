## MODIFIED Requirements

### Requirement: 挑战浏览与参与
系统 MUST 展示本地可用挑战、目标和参与状态，并允许用户加入挑战；参与状态 MUST 使用稳定挑战 ID 持久化到本机。

#### Scenario: 加入挑战
- **WHEN** 用户点击未加入挑战的加入按钮
- **THEN** 系统立即更新界面并持久化参与状态，应用重启后仍保持已加入

### Requirement: 挑战进度计算
系统 SHALL 根据可用的真实 HealthKit 当日摘要和 Core Data 运动记录更新步数、距离或次数进度，不得用固定演示进度替代本地结果。

#### Scenario: 真实数据可用
- **WHEN** 用户的健康摘要或本地运动记录可以支持挑战指标
- **THEN** 系统计算并展示来自这些本地真实数据的进度

#### Scenario: 数据不足
- **WHEN** 计算挑战进度所需的健康权限或样本不可用
- **THEN** 系统保留挑战参与状态，将进度标记为暂无数据并提示需要的数据来源
