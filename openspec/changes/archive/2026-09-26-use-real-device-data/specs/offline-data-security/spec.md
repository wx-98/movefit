## MODIFIED Requirements

### Requirement: 离线可用与持久化
系统 MUST 在无网络时允许查看本地用户数据、完成运动和手动录入，并在应用重启后保留运动记录、个人资料、挑战参与、文章收藏、隐私偏好和未同步操作。

#### Scenario: 离线完成运动
- **WHEN** 用户在无网络环境结束运动
- **THEN** 系统本地保存真实记录并创建具有稳定 ID 的待同步操作

#### Scenario: 恢复本地状态
- **WHEN** 用户重新启动应用
- **THEN** 系统从 Core Data 恢复用户运动、资料、挑战参与、文章收藏和隐私偏好，不恢复模拟账号会话

### Requirement: 最小化健康数据副本
系统 MUST 即时查询 HealthKit 摘要且不复制原始 HealthKit 样本，只持久化 App 自有运动、用户资料和功能必需的本地状态，并为可重建缓存提供明确清理策略。

#### Scenario: 用户清理健康缓存
- **WHEN** 用户触发隐私设置中的本地缓存清理
- **THEN** 系统删除可重建缓存，但不删除 HealthKit 数据、用户运动、个人资料、挑战参与或文章收藏
