## Context

MoveFit 当前具备 HealthKit、CoreLocation、Core Data 和 Keychain 适配器，但默认依赖组装仍注入演示健康数据与带示例记录的仓库；运动会话只保存计时，挑战参与和文章收藏也没有跨启动保存。变更必须继续支持 iOS 15、SwiftUI、Core Data 和纯 Apple 框架，并遵守健康数据最小化、无权限不等于拒绝、日志不记录隐私数据等约束。

## Goals / Non-Goals

**Goals:**

- 默认使用 HealthKit 查询设备真实当日健康摘要，不以演示值填补无样本。
- 户外跑步、步行和骑行记录真实定位点与累计距离，室内运动继续记录真实时长。
- 只展示用户真实创建的运动记录，移除默认运行链路中的示例运动。
- 将挑战参与、文章收藏和隐私偏好持久化，并用真实本地数据刷新可计算进度和建议。
- 为模拟器、未授权、无样本、定位中断和持久化失败提供明确降级。

**Non-Goals:**

- 不接入真实账号认证、远程排行榜、远程内容、云同步或服务端挑战。
- 不实现 HealthKit 写入、后台持续定位、Apple Watch 联动和医疗判断。
- 不用估算值伪装真实能量、心率、距离或健康样本。

## Decisions

### 1. 默认注入真实平台适配器

`MoveFitApp` 默认组装 `HealthKitAdapter`、`LocationAdapter` 和纯 Core Data 的运动 Repository。演示 Provider 只保留给测试和 Preview，不再进入生产启动路径。

选择依赖注入而不是在 View 中直接访问平台框架，使模拟器降级和自动化测试仍可替换数据源。

### 2. HealthKit 使用当日本地日历边界聚合

HealthKit Adapter 使用调用时的 `Calendar`、`TimeZone` 和当前时间生成 `[startOfDay, now]` 范围：步数、步行跑步距离、活动能量和锻炼分钟使用累计统计；站立小时统计 `appleStandHour` 中已站立样本；心率与静息心率读取范围内最新样本。

摘要只在至少存在一个样本时返回。没有样本、读取范围受限或用户未授权统一显示“暂无可用健康数据”，不推断具体授权决定。平台不支持时显示“此设备不支持 Apple 健康”。

### 3. 定位会话由 AppModel 协调

CoreLocation Adapter 负责最小权限、点位质量过滤、路线累计和距离计算；AppModel 根据运动类型决定是否启动定位，并在开始、暂停、继续、结束时驱动 Adapter。View 只发送运动事件和渲染距离。

仅接受水平精度有效且不超过 50 米的点；异常跳点不计入距离。未授权或无有效点时保存时长与空路线，不阻塞运动完成。

### 4. 用户状态统一写入 Core Data

增加挑战状态、文章收藏和应用布尔偏好实体。挑战和文章使用稳定 UUID，避免依赖标题等展示字段。运动写入继续使用稳定操作 ID 保持幂等。

账号模拟会话不持久化，因为它不是真实认证状态；服务端相关数据保持演示或未配置标识。

### 5. 真实数据驱动本地规则

挑战进度从可用的 HealthKit 当日摘要和 Core Data 运动记录派生；无法覆盖完整服务端周期时只显示当前可验证的本地进度。养护建议复用纯领域规则读取当前真实摘要；无摘要时显示通用建议并说明数据不足。

## Risks / Trade-offs

- [HealthKit 无法可靠区分读取拒绝与无样本] → 统一使用中性“暂无可用数据”，仅通过系统授权页让用户管理权限。
- [模拟器没有 HealthKit 数据] → 显示真实空态，测试注入 Fake Provider，不回退到演示数值。
- [GPS 漂移导致距离偏大] → 按精度、时间和跳点距离过滤；真机继续验收城市峡谷和弱信号场景。
- [程序化 Core Data 模型变化缺少版本迁移] → 当前项目尚未发布；新增可选独立实体，不修改既有实体字段。正式发布前改用版本化模型。
- [前台定位无法覆盖锁屏和后台] → 本变更明确只保证前台；后台能力保持未启用并在 README 标注。
- [挑战周期数据不完整] → 只计算本地可验证指标并显示数据来源，不伪造全局进度。

## Migration Plan

1. 新增 Core Data 本地状态实体，保留已有运动和个人资料实体。
2. 将生产依赖从 Demo Provider/Repository 切换到真实 Adapter 与本地 Repository。
3. 首次启动时挑战和文章采用内置稳定 ID；没有本地状态则使用默认未加入/未收藏值。
4. 无需迁移模拟运动、随机挑战 ID 或模拟账号会话，它们不属于用户真实数据。
5. 回滚时可恢复旧依赖组装，新增实体不会影响既有运动和资料读取。

## Open Questions

- HealthKit 写入和后台定位需在后续独立变更中设计授权、恢复与数据所有权策略。
- 服务端可用后，挑战周期口径、远程内容版本和本地状态合并策略需要重新定义。
