## ADDED Requirements

### Requirement: 账户入口与会话状态
系统 SHALL 提供手机号、邮箱、Apple ID 和微信登录入口，并允许未配置远程认证时以本地模式体验非账号依赖功能。

#### Scenario: 使用 Apple ID 登录
- **WHEN** 用户完成 Apple 授权且认证服务可用
- **THEN** 系统建立安全会话并进入主界面

#### Scenario: 远程认证未配置
- **WHEN** 用户选择需要服务端或第三方配置的登录方式
- **THEN** 系统展示明确的暂不可用说明，不得伪造真实登录成功

### Requirement: 个人资料与身体指标
系统 MUST 展示和编辑头像、昵称、身高、体重、BMI 和体脂率，并以明确单位保存身体指标。

#### Scenario: 更新体重
- **WHEN** 用户提交合法体重值
- **THEN** 系统保存新值、重新计算 BMI，并刷新个人资料摘要

### Requirement: 设置与账号控制
系统 MUST 提供健康数据、设备、隐私、帮助、退出登录和账号注销入口。

#### Scenario: 退出登录
- **WHEN** 已登录用户确认退出
- **THEN** 系统清除安全会话，但保留符合数据所有权策略的本地运动记录

#### Scenario: 注销账号
- **WHEN** 用户完成二次确认且远程服务可用
- **THEN** 系统提交注销请求并在成功后清除本地凭据和用户专属缓存
