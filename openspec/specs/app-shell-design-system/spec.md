# 应用壳与设计系统规格

## Purpose

定义五个主导航界面、统一设计令牌、品牌资源和无障碍体验。

## Requirements

### Requirement: 五个主导航界面

系统 MUST 使用固定五 Tab 展示首页、挑战、运动、历史和我的，并在应用重启后回到可用的默认首页。

#### Scenario: 首次进入应用
- **WHEN** 用户完成启动流程进入主界面
- **THEN** 系统展示首页，并允许用户在五个 Tab 之间切换

#### Scenario: 主界面下钻
- **WHEN** 用户从任一 Tab 打开详情、设置或运动会话
- **THEN** 系统保留当前 Tab，并在返回时恢复原页面状态

### Requirement: 统一设计系统

系统 MUST 使用语义化的品牌红、活动红、运动绿、站立蓝、睡眠靛蓝、挑战紫与暖色强调色，以及统一字体、间距、圆角、渐变和阴影令牌构建界面；Feature 不得重复硬编码同类视觉常量。

#### Scenario: 系统外观切换
- **WHEN** 用户选择跟随系统、浅色或深色外观
- **THEN** 所有主页面、详情、图表和通用组件即时使用对应语义颜色并保持可读性

#### Scenario: 展示活动与趋势图表
- **WHEN** 页面展示圆环、柱状图或睡眠阶段
- **THEN** 图表使用一致语义颜色、动态字体替代摘要和无数据样式

### Requirement: 品牌与无障碍

系统 MUST 使用 MoveFit 品牌 Logo、SF Symbols 和本地资源，并为关键控件提供中文无障碍标签及动态字体支持。

#### Scenario: 使用大号动态字体
- **WHEN** 用户启用大号辅助字体
- **THEN** 核心数据和操作保持可见，文本不得被固定高度截断

#### Scenario: 离线加载界面
- **WHEN** 设备无网络连接
- **THEN** 应用图标、Logo、Tab 图标和基础界面仍可完整展示

### Requirement: 卡片交互与详情层级

系统 MUST 为可点击卡片提供明确的视觉反馈、导航标识和无障碍按钮语义，装饰性卡片不得伪装为可点击控件。

#### Scenario: 点击挑战卡片
- **WHEN** 用户点击具有详情的挑战卡片
- **THEN** 系统提供按压反馈并进入对应详情，而不是无响应

### Requirement: 主界面自适应视觉组件

系统 MUST 通过共享 Design System 提供分区标题、指标卡、强调表面、状态胶囊与设置列表行，并在五个主 Tab 复用这些组件。

#### Scenario: 使用辅助大字体
- **WHEN** 用户启用辅助大字体
- **THEN** 核心指标、页面标题、列表行和主要操作不因固定尺寸而被截断或重叠
