# 离线数据与安全规格

## Purpose

定义离线持久化、幂等同步边界、凭据保护与健康数据最小化策略。

## Requirements

### Requirement: 离线可用与持久化

系统 MUST 在无网络时允许查看本地用户数据、完成运动和手动录入，并在应用重启后保留运动记录、个人资料、挑战参与、文章收藏、隐私偏好和未同步操作。

#### Scenario: 离线完成运动
- **WHEN** 用户在无网络环境结束运动
- **THEN** 系统本地保存真实记录并创建具有稳定 ID 的待同步操作

#### Scenario: 恢复本地状态
- **WHEN** 用户重新启动应用
- **THEN** 系统从 Core Data 恢复用户运动、资料、挑战参与、文章收藏和隐私偏好，不恢复模拟账号会话

### Requirement: 幂等同步边界

系统 MUST 使用稳定操作 ID 提交离线变更，并能安全重试而不创建重复运动或收藏。

#### Scenario: 同步请求重复执行
- **WHEN** 同一离线操作因超时被再次提交
- **THEN** Repository 将其视为同一操作并保持单一业务结果

### Requirement: 凭据与敏感数据保护

系统 MUST 将访问令牌存入 Keychain，禁止在日志、UserDefaults、源码和测试夹具中保存真实凭据或健康隐私数据。

#### Scenario: 记录诊断日志
- **WHEN** 网络、HealthKit 或持久化操作失败
- **THEN** 系统只记录脱敏错误类别和追踪标识，不记录身份、位置、健康值或令牌

### Requirement: 最小化健康数据副本

系统 MUST 即时查询 HealthKit 摘要且不复制原始 HealthKit 样本，只持久化 App 自有运动、用户资料和功能必需的本地状态，并为可重建缓存提供明确清理策略。

#### Scenario: 用户清理健康缓存
- **WHEN** 用户触发隐私设置中的本地缓存清理
- **THEN** 系统删除可重建缓存，但不删除 HealthKit 数据、用户运动、个人资料、挑战参与或文章收藏

### Requirement: 主动健康记录最小化保存

系统 MUST 仅在本机保存用户主动录入的最小健康管理字段，并允许清理；不得保存 ECG 原始波形或将其写入日志。

#### Scenario: 清理健康管理记录
- **WHEN** 用户选择删除或清理记录
- **THEN** 系统删除目标本地记录且不影响 HealthKit 原始数据
