# 活动历史规格

## Purpose

定义活动历史的周期聚合、运动列表、趋势与路线摘要行为。

## Requirements

### Requirement: 周期筛选与聚合

系统 MUST 支持周、月、六个月和年四种步数周期，并按显式日历、时区和当前时间生成稳定的日、周或月分桶；每次切换必须重新计算日期范围、平均步数、今日对比和运动列表。

#### Scenario: 切换到月视图
- **WHEN** 用户将历史周期从周切换为月
- **THEN** 系统按周分桶更新横坐标、平均步数、今日对比和运动列表，且柱体不越界或重叠

#### Scenario: 切换到年视图
- **WHEN** 用户将历史周期切换为年
- **THEN** 系统按月分桶展示趋势并使用与柱体数量一致的横坐标

### Requirement: 历史运动列表

系统 MUST 合并 Core Data 与 HealthKit 的运动，使用来源和稳定 ID 去重，按开始时间倒序展示类型、来源、时间、时长、距离和能量，并支持进入详情。

#### Scenario: 新记录出现在历史中
- **WHEN** 用户完成或手动添加一条运动记录
- **THEN** 历史列表在刷新后展示该记录且不产生相同来源 ID 的重复项

#### Scenario: 读取 Apple 设备运动
- **WHEN** HealthKit 返回 iPhone、Apple Watch 或其他已同步来源的运动样本
- **THEN** 历史列表展示所有可读取且支持映射的运动，并标记 Apple 健康来源

### Requirement: 趋势与路线摘要

系统 SHALL 使用 iOS 15 兼容的图形组件展示步数与热量趋势，并为具有路线点的运动展示地图摘要。

#### Scenario: 记录没有路线
- **WHEN** 用户查看室内运动或位置不可用的运动
- **THEN** 系统隐藏地图并继续展示其他运动指标

### Requirement: 运动详情

系统 SHALL 为历史记录展示来源、时间、时长、距离、能量和可用路线，并对缺失字段提供明确空态。

#### Scenario: 查看 HealthKit 运动详情
- **WHEN** 用户点击来自 Apple 健康的运动
- **THEN** 系统展示可读取摘要和来源说明，不虚构不可读取的路线或分段数据

### Requirement: 趋势图交互与对比

系统 SHALL 在步数趋势中展示可读柱状图、平均线和今日步数线，并允许用户选择柱体查看对应日期范围与步数；系统必须说明今日步数高于、低于或接近平均值。

#### Scenario: 选择趋势柱体
- **WHEN** 用户点击一个步数柱体
- **THEN** 系统高亮该分桶并展示其日期范围、步数与相对平均值

#### Scenario: 今日数据不可比较
- **WHEN** 当前周期缺少今日步数或有效历史平均值
- **THEN** 系统展示数据不足状态而不推断今日多或少

### Requirement: 历史数据回顾视觉层级

系统 MUST 将历史页组织为周期选择、运动汇总、趋势解释和记录时间线，并保持图表选择状态与记录入口可识别。

#### Scenario: 用户切换统计周期
- **WHEN** 用户切换周、月、半年或年
- **THEN** 周期控件、汇总值、趋势图和已选柱体信息以一致的层级更新
