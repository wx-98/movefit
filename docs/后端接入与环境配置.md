# MoveFit 后端接入与环境配置

## 1. 当前服务

| 服务 | 本地地址 | 客户端职责 |
| --- | --- | --- | --- |
| 主业务后端 | `http://127.0.0.1:8000` | 认证、社交身份、资料、运动、训练计划、挑战、文章、帮助、工单和客户端配置 |
| 动作目录后端 | `http://127.0.0.1:8001` | 版本化动作查询、过滤、分页和图片 |
| AI 健康洞察后端 | `http://127.0.0.1:8002` | AI 洞察权益查询与聚合指标分析 |

## 2. 修改后端地址的位置

地址不写在 View、AppModel 或 Repository 中。

1. [Configuration/Info.plist](../Configuration/Info.plist) 定义：
   - `MoveFitBackendBaseURL = $(MOVEFIT_BACKEND_BASE_URL)`
   - `MoveFitExerciseBaseURL = $(MOVEFIT_EXERCISE_BASE_URL)`
   - `MoveFitAIBaseURL = $(MOVEFIT_AI_BASE_URL)`
   - `MoveFitGoogleRedirectURI = $(MOVEFIT_GOOGLE_CALLBACK_SCHEME):/oauth2redirect`
2. [MoveFit.xcodeproj/project.pbxproj](../MoveFit.xcodeproj/project.pbxproj) 的 MoveFit Target Build Settings 定义 Debug/Release 默认值。
3. [MoveFit/App/AppEnvironment.swift](../MoveFit/App/AppEnvironment.swift) 只负责读取和校验 URL，不保存具体环境常量；Release 拒绝 HTTP、环回、数字 IP、开发占位域名，配置不合法时不会静默回退本机。

默认值：

| Configuration | 主业务地址 | 动作地址 | AI 地址 |
| --- | --- | --- |
| Debug | `http://127.0.0.1:8000` | `http://127.0.0.1:8001` | `http://127.0.0.1:8002` |
| Release | `https://api.movefitgo.com` | `https://exercises.movefitgo.com` | `https://ai.movefitgo.com` |

已部署环境：

| Environment | 主业务地址 | 动作地址 | AI 地址 |
| --- | --- | --- | --- |
| Staging | `https://staging-api.movefitgo.com` | `https://staging-exercises.movefitgo.com` | `https://staging-ai.movefitgo.com` |
| Production | `https://api.movefitgo.com` | `https://exercises.movefitgo.com` | `https://ai.movefitgo.com` |

Release 默认使用生产 HTTPS 域名；它们只是构建配置，不代表线上当前可达。上线前确认实际 DNS、证书与 API 验收，并按 Google OAuth 客户端配置回调 scheme。也可由 CI 在 `xcodebuild` 命令中覆盖：

```bash
xcodebuild \
  -project MoveFit.xcodeproj \
  -scheme MoveFit \
  -configuration Release \
  MOVEFIT_BACKEND_BASE_URL=https://api.movefitgo.com \
  MOVEFIT_EXERCISE_BASE_URL=https://exercises.movefitgo.com \
  MOVEFIT_AI_BASE_URL=https://ai.movefitgo.com \
  MOVEFIT_GOOGLE_CALLBACK_SCHEME=com.movefit.mobile \
  archive
```

真机 staging 验收使用显式 Debug 覆盖，不修改仓库默认值：

```bash
xcodebuild \
  -project MoveFit.xcodeproj \
  -scheme MoveFit \
  -configuration Debug \
  -destination 'platform=iOS,id=<真机设备ID>' \
  MOVEFIT_BACKEND_BASE_URL=https://staging-api.movefitgo.com \
  MOVEFIT_EXERCISE_BASE_URL=https://staging-exercises.movefitgo.com \
  MOVEFIT_AI_BASE_URL=https://staging-ai.movefitgo.com \
  build
```

生产地址必须使用 HTTPS。不要把 Token、密码、验证码证明或签名密钥写入这些配置。

## 3. 模拟器与真机

- Debug 默认使用 `127.0.0.1`，适合在同一 Mac 上运行后端的模拟器。
- `127.0.0.1` 在 iPhone 真机中指向手机自身，不能作为 Mac 后端地址。
- 真机优先使用上述 staging HTTPS 覆盖；若测试本机后端，可临时用当前 Mac 的局域网地址覆盖三个 Debug 变量，并确保服务监听可访问网卡及防火墙放行。
- 主业务后端必须以 `--host 0.0.0.0 --port 8000` 启动；当前动作服务已监听可访问网卡。
- 更换开发机或网络时，只覆盖构建参数，不提交个人局域网地址；生产构建不得扩大为任意 HTTP 访问。

## 4. 接口与代码映射

| 后端接口 | 客户端实现 | 使用位置 |
| --- | --- | --- |
| `POST /api/v1/auth/verification-challenges` | `BackendRepository.requestChallenge` | 请求邮箱或短信验证码 |
| `POST /api/v1/auth/verification-challenges/{challenge_id}/verify` | `BackendRepository.confirmChallenge` | 确认六位验证码并取得一次性证明 |
| `POST /api/v1/auth/register` | `BackendRepository.register` | 账户注册 |
| `POST /api/v1/auth/login/password` | `BackendRepository.signIn` | 邮箱/手机号登录 |
| `POST /api/v1/auth/token/refresh` | `MoveFitAPIClient.refreshTokens` | 受保护请求首次 401 |
| `POST /api/v1/auth/logout(-all)` | `BackendRepository.signOut` | 当前/全部设备退出 |
| `GET /api/v1/me` | `BackendRepository.currentProfile` | 登录恢复与资料刷新 |
| `PATCH /api/v1/me/profile` | `BackendRepository.updateProfile` | 带 `base_version` 的资料更新 |
| `GET /api/v1/workouts` | `BackendRepository.workouts` | 读取全部 cursor 页并合并历史 |
| `POST /api/v1/workouts` | `BackendRepository.upload` | 本地保存成功后的幂等上传 |
| `GET /api/v1/client-config` | `BackendRepository.configuration` | 服务状态与配置修订 |
| `GET /api/v1/training-plans` | `RemoteTrainingCatalogRepository` | 按语言读取完整游标目录；失败时明确显示本地离线方案 |
| `GET /v1/exercises` | `RemoteExerciseCatalogRepository` | 动作分页、过滤与图片 |
| `GET /api/v1/health-insights/access` | `RemoteAIHealthInsightRepository` | 查询真实 AI 洞察可用性与权益状态 |
| `POST /api/v1/health-insights/analyze` | `RemoteAIHealthInsightRepository` | 使用 Bearer Token 与 `Idempotency-Key` 请求 AI 洞察 |
| `POST /api/v1/auth/login/{apple,wechat,google}`、`POST /api/v1/auth/login/google/authorization` | `BackendRepository+SocialIdentity`、平台授权 Adapter | 授权成功后建立 Keychain 会话 |
| `GET /api/v1/auth/identities`、`/api/v1/auth/identities/{provider}/link`、`DELETE /api/v1/auth/identities/{provider}` | `BackendRepository+SocialIdentity` | 读取脱敏绑定状态，以稳定幂等键写入 |
| `GET /api/v1/challenges`、详情、参与、排行榜 | `BackendRepository+Challenge` | 远端挑战与隐私化排行榜 |
| `GET /api/v1/articles`、详情及 `/api/v1/me/article-favorites` | `BackendRepository+Content` | 文章阅读和认证收藏 |
| `GET /api/v1/help-articles`、`/api/v1/support/tickets` | `BackendRepository+Support` | 帮助文章和本人工单操作 |

关键文件：

- `MoveFit/Data/Networking/MoveFitAPIClient.swift`：请求、错误、Bearer 与刷新重试。
- `MoveFit/Data/Networking/BackendSessionStore.swift`：Keychain 会话。
- `MoveFit/Data/Networking/BackendRepository.swift`：主后端 DTO 和 Domain 映射。
- `MoveFit/Domain/RegistrationVerification.swift`：邮箱/E.164、六位码和注册状态机。
- `MoveFit/Domain/RegistrationVerificationUseCases.swift`：请求挑战及“确认后立即注册”的应用流程。
- `MoveFit/Features/Profile/RegistrationViewModel.swift`：倒计时、重发、取消和敏感状态清理。
- `MoveFit/Platform/KeychainInstallationIdentity.swift`：不含 PII 的随机安装 UUID。
- `MoveFit/Data/Networking/RemoteExerciseCatalogRepository.swift`：动作后端与内置降级。
- `MoveFit/Data/Networking/AIHealthInsightAPIClient.swift`：AI 服务 Bearer 请求与 DTO 映射；不尝试在 AI 域名刷新主业务令牌。
- `MoveFit/Data/Networking/RemoteAIHealthInsightRepository.swift`：AI 权益、聚合指标请求及领域映射。
- `MoveFit/App/MoveFitApp.swift`：生产依赖装配。
- `MoveFit/App/AppModel.swift`：加载、合并、本地优先保存和 UI 状态协调。
- `MoveFit/App/RemoteFeatureViewModel.swift`：社交身份、挑战、文章、帮助和工单的远端状态及写入。
- `MoveFit/Platform/GoogleOAuthAdapter.swift`：系统浏览器 OAuth 回调校验与 PKCE；不保存授权码。

## 5. 数据行为

- 登录令牌：只保存在 Keychain。401 最多刷新并重放一次；刷新失败清除会话。
- 验证码注册：先用规范化邮箱或 E.164 手机号（例如 `+8613800000000`）、渠道和 Keychain 安装 UUID 请求挑战；再用 `challenge_id`、同一安装 UUID 和六位码确认；客户端取得一次性证明后立即以同一规范化标识注册。证明不展示、不记录、不持久化，改变标识或离开页面会使当前挑战失效。
- Provider 边界：邮件由后端 SMTP 投递，短信由后端腾讯云投递，iOS 始终只依赖上述通用挑战接口。`TENCENT_SECRET_ID`、`TENCENT_SECRET_KEY`、`TENCENT_SMS_SDK_APP_ID`、`TENCENT_SMS_SIGN_NAME`、`TENCENT_SMS_TEMPLATE_ID` 只能存在于后端/Coolify Secret；不得进入 iOS 源码、Build Settings、Info.plist、UserDefaults、Core Data、分析事件或日志。
- 降级边界：Provider 不可用的 503 只影响验证码注册；已有用户的密码登录和 Keychain 会话恢复继续可用。
- 个人资料：服务端支持昵称、身高、体重和体脂，更新携带 `base_version` 与 `Idempotency-Key`。
- 运动：running、walking、cycling、yoga、strength、hiit 可上传；其他类型只保存在本机并明确提示。
- HealthKit：继续直接从设备读取，不自动批量上传原始健康样本。
- 动作：远程成功显示目录版本；失败切换随包内容，并显示失败原因和降级来源。
- 客户端配置：读取 revision、`feature_enabled` 和 `sync_interval_seconds`；在产品语义未定义前不使用 `feature_enabled` 关闭整个 App。
- AI 洞察：仅发送指标类型、当前值、近期平均值、单位和周期；不发送 ECG 波形、精确位置、原始 HealthKit 样本、姓名、邮箱或手机号。未登录、服务不可达或无权益时保留本地洞察。
- 社交身份：Apple 使用系统授权码与 nonce；Google 使用 `ASWebAuthenticationSession` 和 PKCE S256，`MoveFitGoogleRedirectURI` 必须与后端允许列表和 Google OAuth 客户端配置一致。微信目前是明确不可用的授权码 Adapter，需开放平台 SDK、App ID 与 Universal Link 后才能真机登录。取消授权不会覆盖 Keychain 现有会话。
- 社交绑定/解绑依赖后端 `add-social-identity-write-idempotency` change 部署。挑战参与、文章收藏和工单写入使用稳定 `Idempotency-Key`；Google 登录返回的 token pair 不缓存为可重放响应。
- 挑战目录、文章、帮助文章优先展示服务端发布数据，读取失败时仅显示已缓存或随包内容并标明来源。Challenge worker 未消费运动事件时展示上次服务端进度，不在客户端猜测完成。

## 6. 尚需部署配置的能力

- Apple：在 Apple Developer 配置 Sign in with Apple、应用 Bundle ID，并在后端配置验证所需的 Provider 参数。
- Google：配置 OAuth 客户端、后端 redirect allowlist 与客户端 `MOVEFIT_GOOGLE_CALLBACK_SCHEME`；三处 URI 必须完全一致。Debug 默认回调为 `com.movefit.mobile:/oauth2redirect`，真机须验证授权成功、取消与错误回调。
- 微信：当前未打包开放平台 SDK；完成 App ID、Universal Link 与合规审查后，替换 `UnavailableWechatAuthorizationAdapter`，不要在 App 中硬编码 Secret。
- Challenge worker：需部署并运行；客户端只展示服务端最新进度，不替代后台计算。
- 账号注销：后端暂无正式契约，客户端不提供模拟操作。

## 7. 验证

服务连通性：

```bash
curl --fail http://192.168.31.126:8000/health/ready
curl --fail 'http://192.168.31.126:8000/api/v1/client-config?platform=ios&app_version=1.0.0'
curl --fail 'http://192.168.31.126:8001/v1/exercises?page=0&page_size=1'
curl --fail http://192.168.31.126:8002/health/ready
curl --fail http://192.168.31.126:8002/api/v1/health-insights/access
```

iOS 自动化测试使用自定义 `URLProtocol`，不会依赖真实账号或修改本地服务数据，覆盖：

- 正确路径与查询参数；
- 客户端配置映射；
- 401 → Refresh Token → 单次重试；
- 运动 cursor 全分页和单位映射；
- 动作 `page_size`、难度、图片映射；
- 动作服务离线时的内置降级。
- 邮箱/E.164 校验、挑战/确认/注册三步 DTO、六位码、倒计时、429 `Retry-After`、503 降级、标识改变失效及敏感数据不落盘。

xcodebuild \
  -project MoveFit.xcodeproj \
