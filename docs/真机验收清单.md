# MoveFit 真机验收清单

## Apple 健康

- [ ] 首次连接时仅出现步数、距离、活动能量、锻炼、站立、心率、睡眠和运动读取请求。
- [ ] 全部允许后，首页数据与“健康”App 当日样本一致，单位和日期边界正确。
- [ ] 部分允许时，已授权且有样本的指标正常显示，其余指标显示“—”。
- [ ] 全部拒绝、撤销授权或当天无样本时显示“暂无数据”，不出现演示数值。
- [ ] 下拉刷新和设置页“连接或刷新 Apple 健康”可重新读取。
- [ ] 应用未申请 HealthKit 写权限，完成运动后不会写入“健康”App。
- [ ] 首页活动圆环居中，活动/锻炼/站立三个比例与实际样本和目标一致。
- [ ] 趋势详情的 7/30/180/365 天样本、日均、总量和最佳日与“健康”App 日期范围一致。
- [ ] 首页的步数、距离、当前心率和静息心率均可进入详情；近 30 天柱状图可点击，并显示选中日期、平均线和真实数据来源。
- [ ] 心率/静息心率详情在支持 ECG 且有授权记录的真机上显示系统分类摘要、时间和来源；点按历史记录可显示该条记录的电压波形。波形只在内存显示，不保存、不上传、不作异常诊断。ECG 无样本或权限不足不应遮蔽心率详情。
- [ ] 健康洞察只描述当前值与平均值的趋势，明确非诊断；未接入远程 AI 时显示本地洞察与权益预留说明。
- [ ] 睡眠详情的入睡/醒来、总睡眠、在床、核心、深睡、快速眼动和效率与可读样本一致。
- [ ] 睡眠样本不足时不显示伪造评分；评分说明明确为本地参考算法。
- [ ] 历史页可看到 Apple Watch/iPhone 已同步到健康 App 的全部可映射运动，缺少路线或热量时记录仍存在。

## 户外运动定位

- [ ] 首次开始跑步、步行或骑行时只申请“使用 App 期间”定位。
- [ ] 在应用前台移动一段可见距离，运动页累计距离持续更新。
- [ ] 暂停期间停止累计；继续后从新定位点合理衔接，不计入明显漂移或跳点。
- [ ] 结束后，历史页显示真实时长、距离和 MapKit 路线。
- [ ] 拒绝定位后仍能保存运动时长，距离为空且不显示路线。
- [ ] 瑜伽、力量和 HIIT 不触发定位请求。
- [ ] 切到后台或锁屏时不把路线连续性作为通过条件；当前版本不支持后台定位。

## 本地持久化

- [ ] 手动记录和设备运动在杀掉应用并重新启动后仍存在。
- [ ] 个人资料、挑战加入、文章收藏和身体指标遮挡偏好可恢复。
- [ ] 外观与语言偏好重新启动后可恢复，跟随系统模式能响应系统外观。
- [ ] 未填写个人资料时身高、体重和 BMI 显示空值，不出现默认指标。
- [ ] 全新安装时历史为空，不出现内置示例运动或示例路线。
- [ ] 清理可重建缓存后，运动、资料、挑战、收藏和隐私偏好仍保留。
- [ ] 首页可进入症状记录、用药提醒、饮食与营养、检查记录四个页面；每类均可添加与删除本地记录，并显示历史、近 7 天趋势与非诊断性提示。
- [ ] 用药页面可逐项标记完成，营养页面可保存千卡、蛋白质和碳水；重新启动后四类记录仍存在。
- [ ] 主动健康管理记录不出现在网络请求、日志、HealthKit 写入或服务端同步中。

## 服务端边界

- [ ] 本地 Debug 构建中的三个服务地址均为当前开发机的局域网地址而非 `127.0.0.1`；staging 使用 `https://staging-api.movefitgo.com`、`https://staging-exercises.movefitgo.com`、`https://staging-ai.movefitgo.com`；production 使用对应的 `api`、`exercises`、`ai.movefitgo.com` HTTPS 地址。
- [ ] 主业务、动作和 AI 服务可从真机访问各自的 readiness/公开接口，证书链和域名校验正常。
- [ ] 邮箱/手机号使用真实后端登录；正确凭据建立会话，错误凭据显示服务端错误，杀掉 App 后可从 Keychain 恢复会话。
- [ ] 邮箱注册按“请求验证码 → 输入六位码确认 → 同一规范化邮箱立即注册”完成；界面不出现一次性证明字段。
- [ ] 手机注册只接受 E.164（例如 `+8613800000000`），按同样三步流程完成腾讯云短信投递、确认与注册。
- [ ] 错误验证码显示稳定、安全且可重试的错误；不展示 Provider 原始响应，也不创建本地模拟账号。
- [ ] 发送后倒计时期间不能重复发送；倒计时结束可重发，快速双击只产生一次请求。
- [ ] 429 按合法 `Retry-After` 更新等待时间；缺失或无效头使用安全默认值；503 明确说明投递暂不可用。
- [ ] 发送后修改邮箱/手机号会清除挑战、验证码和一次性证明，必须对新标识重新发送。
- [ ] 注册成功后回到登录状态并预填规范化标识；验证码、密码和一次性证明不出现在 UI、日志、UserDefaults 或 Core Data。
- [ ] 邮件/短信投递 503 时，已有用户密码登录和 Keychain 会话恢复仍正常。
- [ ] 腾讯云 SecretId/SecretKey、短信应用 ID、签名和模板 ID 仅存在于后端/Coolify，App 包、源码、Build Settings、Info.plist、分析事件和日志中均不存在。
- [ ] Access Token 过期后仅刷新并重试一次；Refresh Token 无效时清除会话并要求重新登录。
- [ ] 登录后个人资料通过服务端读取和更新，版本冲突不会覆盖服务端新数据。
- [ ] 登录后历史合并服务端全部 cursor 分页；MoveFit 新运动先本地保存再上传，离线失败不丢记录。
- [ ] Apple 授权成功后调用主后端、Keychain 保存会话；取消或后端错误不覆盖已有会话。
- [ ] Google `com.movefit.mobile:/oauth2redirect` 与 iOS URL scheme、后端 allowlist、OAuth 客户端配置一致；完成授权后建立会话，取消、state 不匹配和 PKCE 失败均不建立会话。
- [ ] 微信 SDK/Universal Link 未配置时显示明确不可用，不生成模拟授权码、令牌或绑定结果；配置完成后用真实授权码验收。
- [ ] 账号绑定页读取 Apple/微信/Google 脱敏身份与绑定时间；绑定与解绑成功后刷新，最后一种可登录身份不可解绑时保留会话并显示明确错误。
- [ ] 服务端挑战目录和本机 60 条挑战清晰分区；服务端详情展示目标、截止时间、本人参与和 worker 上次计算进度，不用本机指标伪造进度。
- [ ] 加入/退出服务端挑战失败时不显示成功；同一次网络失败重试复用 `Idempotency-Key`。未登录时提示登录，不创建伪参与。
- [ ] 排行榜只显示服务端隐私别名、名次、进度和本人标记；可加载下一页，离线不展示演示用户。
- [ ] 已发布文章、详情、帮助文章优先来自服务端；离线时标明随包或本次会话缓存来源。
- [ ] 文章收藏/取消收藏只在登录且服务端确认后更新；网络失败时不显示成功。
- [ ] 登录用户可创建、查看、回复和关闭本人工单；未登录不可写，网络失败重试保持原操作 ID，日志和分析事件没有正文。
- [ ] 后端 `add-social-identity-write-idempotency` change 已部署，Challenge worker 在运行；社交绑定与挑战状态通过真实服务端验证。
- [ ] 动作服务可用时显示真实版本和图片；服务不可达时可离线查看基础动作并明确标记内置降级。
- [ ] 含两张 `images` 的动作详情能分别看到“起始动作”和“结束动作”，左右切换正确；缺图或下载失败有可读占位状态。
- [ ] “后端服务”页显示三个地址、客户端配置修订和当前连接状态，可主动重试。
- [ ] 离线状态不影响 HealthKit、本地运动、资料、挑战、收藏和本地文章。
- [ ] 挑战页可显示并筛选 60 条本地挑战模板；已参加的旧版挑战在升级后仍保持参加状态。
- [ ] 历史页切换周、月、半年、年后，步数趋势坐标均完整可读；点击柱体显示对应日期/区间，今日相对平均的说明不将缺失数据解释为低于平均。

## 通用质量

- [ ] 五个 Tab 均使用大标题、重点摘要与分区标题；浅色、深色模式下没有固定白色背景或对比不足的文字。
- [ ] 在辅助大字体下，首页重点指标、挑战卡、运动类别、历史汇总和我的设置行没有截断、重叠或无法点击的主要操作。
- [ ] AppIcon 无透明通道，启动页和五个 Tab 显示正确。
- [ ] 深色模式、辅助大字体和 VoiceOver 下关键导航与按钮可用。
- [ ] 使用 Instruments 观察前台户外运动的定位耗电，无异常持续请求。
- [ ] 日志中没有健康指标、精确位置、账号标识、令牌或完整系统响应。
- [ ] 活动圆环、趋势、睡眠、挑战详情、运动分类、动作详情、历史详情和设置页支持 VoiceOver。
